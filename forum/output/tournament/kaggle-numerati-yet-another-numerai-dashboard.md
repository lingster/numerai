# Kaggle Numerati: Yet Another Numerai Dashboard

---

### Post #1 — **svendaj** | 2024-06-24 10:47 UTC

Thanks to [@ia_ai](</u/ia_ai>) and [@numerologist](</u/numerologist>) we have two great apps to compare our results and models. I have become frequent user of both [Shiny Numerati](<https://huggingface.co/spaces/jofaichow/shiny-numerati>) and [YAND](<https://yand.pythonanywhere.com/>), but then I struggled with the first step of usage: model or user selection (YAND). Moreover, my interest was relatively stable and I needed to select the same set of models/accounts over and over again. So, I have decided to build my own dashboard in Kaggle notebook and make it public.

# Check [**KAGGLE NUMERATI**](<https://www.kaggle.com/code/svendaj/kaggle-numerati>)
