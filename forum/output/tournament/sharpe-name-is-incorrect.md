# Sharpe name is incorrect

---

### Post #1 — **petya** | 2020-07-29 10:10 UTC

Strictly speaking, if you compute mean(daily correlations)/stdev(daily correlations), this is called Information Ratio, not Sharpe Ratio (which is computed from daily portfolio returns, not daily correlations).
