# No Xmas data release

---

### Post #1 — **profricecake** | 2021-12-25 18:16 UTC

For those awaiting the Xmas data release (as I was), I saw on the chat that it has been postponed until March.

Here is the message:

> We have decided not to release new features this month as previously planned. Instead, we will be pushing the improvements that were planned for this month to go into the March data release. This is expected to have a few new features, but more importantly to have all of the test targets released as well. We’ll give more information about that release as we get closer to that time, but for now just enjoy the holidays!
