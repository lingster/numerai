I would like to propose a redesign of the Daily Scoring Status on [Numerai](<https://numer.ai/scores>).

Although it does provide a quick pipeline status, the details are hidden until you do a mouse over, and then they disappear. What I propose is a simple table for all the relevant information:

One other change I’d like to propose is in the Compare Score chart. The default display is CORJ60, and I would prefer it to be MMC. Ideally users should be able to set the default. I also recommend a new chart which applies the current multipliers and graphs V2_CORR20 and MMC (e.g., SCORE = V2_CORR20 _0.5 + MMC_ 2).
