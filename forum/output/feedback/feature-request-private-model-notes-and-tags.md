# Feature request: Private model notes and tags

---

### Post #1 — **minou** | 2022-01-17 13:38 UTC

Couple of feature requests.

  1. It would be useful to be able to set a short private note for each model slot and have these appear below the model name in the account models list. These could be editable by clicking a note or via the “More” menu, and would supplement notes about models that a user might keep elsewhere.

  2. There are many ways that a subset of model slots could be usefully grouped together, and associating arbitrary tags with model slots could support this. Given a tagging feature, filtering, grouping and sorting by tags in areas such as the models list and the chart area would then be a great addition.
