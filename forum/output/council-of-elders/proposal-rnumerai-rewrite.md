# [Proposal] RNumerai Rewrite

---

### Post #1 — **theomniacs** | 2022-05-27 21:56 UTC

Fun Fact: Did you know that the Rnumerai package on CRAN has been downloaded over 23,000 times?

[![image](https://canada1.discourse-cdn.com/flex009/uploads/numerai/optimized/2X/0/0cd5a39e75418fde49dea08d77c52db532077f3f_2_131x500.jpeg)image228×864 152 KB](<https://canada1.discourse-cdn.com/flex009/uploads/numerai/original/2X/0/0cd5a39e75418fde49dea08d77c52db532077f3f.jpeg> "image")

Since its debut in 2017, it has received some solid praise, adoption and appreciation.

[![image](https://canada1.discourse-cdn.com/flex009/uploads/numerai/original/2X/d/dafa908996b682cd109fc6a116c505c405c9157a.png)image396×352 12.7 KB](<https://canada1.discourse-cdn.com/flex009/uploads/numerai/original/2X/d/dafa908996b682cd109fc6a116c505c405c9157a.png> "image")

Problem: Despite its darling status among R tournament participants, RNumerai is in need of some serious love. It hasn’t had a substantial rewrite in nearly 5 years.

[![image](https://canada1.discourse-cdn.com/flex009/uploads/numerai/original/2X/3/384aa9bd75f628a5e0cc2d1eab01a514bb7ac159.png)image624×270 53.5 KB](<https://canada1.discourse-cdn.com/flex009/uploads/numerai/original/2X/3/384aa9bd75f628a5e0cc2d1eab01a514bb7ac159.png> "image")

…and “the streets” are begging for a new version…

[![image](https://canada1.discourse-cdn.com/flex009/uploads/numerai/original/2X/c/c9a7cd21716c444789a38afeee37b4c7b1b6f808.png)image624×223 60.7 KB](<https://canada1.discourse-cdn.com/flex009/uploads/numerai/original/2X/c/c9a7cd21716c444789a38afeee37b4c7b1b6f808.png> "image")

Proposal: The Omni Analytics team will do a complete rewrite of the RNumerai package to better support automated model submission and return the package to its former glory. This will include code refactoring, improved documentation and the incorporation of the new model assessment metrics into the package.

Deliverable: A fully updated and functioning package hosted on both Github and CRAN.

Compensation: $5,000 in $NMR (50 man-hrs @ $100/hr) with 50% dispersed at the start and 50% upon successful re-submission to CRAN.

NMR Wallet Addy: 0x00000000000000000000000000000000000033b0

We look forward to getting back to supporting the Numerai community! ![:slight_smile:](https://emoji.discourse-cdn.com/twitter/slight_smile.png?v=13)
