My [proposal](<http://forum.numer.ai/t/proposal-around-the-world-with-numeratis/5301/5>) for the global Numerai community meetup has been accepted. Thanks for all the feedback!

Now we need to pick a location for the very first event. The goal is to organize the first event ASAP so that we can get a cost estimate for future events.

I looked at the data from my [old dashboard](<https://www.jofaichow.co.uk/numerati/>) and picked ten feasible (at least for me … in terms of logistics and travel restrictions) options for the first event.
