# Discourse-math plugin now available

---

### Post #1 — **pschork** | 2020-08-20 01:57 UTC

We’ve enabled the [discourse-math](<https://meta.discourse.org/t/discourse-math-plugin/65770>) plugin powered by [MathJax](<https://www.mathjax.org/>) so now you can include nice formulas like \sigma = \sqrt{ \frac{1}{N} \sum_{i=1}^N (x_i -\mu)^2}  in your forum posts!

The formula above is generated from this markdown
    
    
    $\sigma = \sqrt{ \frac{1}{N} \sum_{i=1}^N (x_i -\mu)^2}$
