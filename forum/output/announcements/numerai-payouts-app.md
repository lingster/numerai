# Numerai Payouts

**Numerai Payouts** is an app made independently by [ceunen](<https://numer.ai/ceunen_>) to track pending payouts of Numerai models.

For any bug reporting and for feature requests for future consideration, reach out to Ceunen directly at bouwe.ceunen@gmail.com or in [RocketChat](<https://community.numer.ai/direct/ceunen>).  
Follow [Numerai Payouts](<https://twitter.com/numeraipayouts>) on Twitter for updates on new releases.

_Disclaimer: Numerai is not involved in the development or maintenance of this app_

## Download

  * [App Store](<https://apps.apple.com/app/id1522158691>)
  * [Google Play](<https://play.google.com/store/apps/details?id=app.numeraipayouts.numerai_payouts>)



## Usage

### API Keys

`View user info` permission API keys are needed to get all your models without you entering them manually one by one. It will also automatically update models if you add one. The `View user info` permission API keys are read-only and are solely there to take away the manual labor of putting your models in one by one.

For those who prefer not to give out their API keys, it is possible to manually add your models.

### Payout Calculation

The total amount of pending payouts you see next to each model already has the leaderboard bonus added to it. Because this will be discontinued in the near future, it’s not shown in the app.

[![model](https://canada1.discourse-cdn.com/flex009/uploads/numerai/optimized/1X/082f5bfe6de253a84039164e09dc8f1fdb06c55a_2_690x321.png)model862×402 51.2 KB](<https://canada1.discourse-cdn.com/flex009/uploads/numerai/original/1X/082f5bfe6de253a84039164e09dc8f1fdb06c55a.png> "model")

Model name is displayed on the top. The header below it contains your current rank on the leaderboard, the current stake associated with that model and the pending payout.

Each row has the round number at the left, Correlation, MMC and payout of that round.
